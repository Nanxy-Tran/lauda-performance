# Lauda Performance

Expo ([React Native](https://reactnative.dev/)) telemetry app — oscilloscope / suspension HUD, GPS logging, and brake analyzer tabs.

## Develop

```bash
npm install
npx expo start
```

Production-style runs use a [development build](https://docs.expo.dev/develop/development-builds/introduction/) (`npm run android` / `npm run ios` after `npm run prebuild` if native folders exist).
